# data/assets/fonts/

Fuentes propias del producto:

- **Outfit** — UI general (botones, menús, títulos secundarios).
- **Cormorant Garamond** — Tipografía display (títulos de pantalla).
- **Libre Baskerville** — Cuerpo de versículos y letras de cantos.

Ver `data/assets/README.md` para cómo descargarlas.
